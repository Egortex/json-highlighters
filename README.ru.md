# json-highlighters

[English](./README.md) · **Русский**

Монорепозиторий (npm workspaces) с библиотекой `@chepchik/json-highlighters`
(живая редактируемая подсветка синтаксиса JSON и YAML для React 18/19) и
демо-приложением, где все её редакторы стоят рядом.

- `packages/json-highlighters/` — библиотека, публикуется в npm
- `example/` — демо-приложение (Vite + React)
- `e2e/` — Playwright-тесты против демо

## Что это

Четыре компонента-редактора, у каждого свой подход:

- **`RegexHighlighter`** — один regex размечает сырой текст; прозрачная
  `<textarea>` лежит поверх цветного `<pre>`. Работает и на временно
  невалидном JSON.
- **`AstPositionHighlighter`** — самописный токенизатор, который сохраняет
  позицию каждого токена в исходной строке; то же наложение слоёв, но
  раскраска по грамматике, а не по догадке regex.
- **`AstContentEditableHighlighter`** — редактирование прямо внутри цветного
  `contentEditable`-элемента; перекраска с дебаунсом, курсор
  восстанавливается после каждой перерисовки.
- **`YamlHighlighter`** — построчный YAML-аналог regex-варианта.

Компоненты рендерят **только редактор**. Выбор отступа, кнопку
«Форматировать» и галочку валидности для JSON-редакторов рисует приложение-хост:
флаг приходит через `onValidityChange`, форматирование вызывается через
`ref.current?.format()`. У YAML нет ни форматирования, ни колбэка валидности.
Проверка валидности AST-редакторов допускает больше, чем `JSON.parse`;
см. ограничения в README библиотеки.

Полная документация: [`packages/json-highlighters/README.ru.md`](./packages/json-highlighters/README.ru.md).

## Разработка

Команды запускаются из корня репозитория:

```bash
npm install          # установка workspaces; prepare собирает библиотеку
npm run build:lib    # сборка библиотеки, включая CSS
npm run dev          # Vite dev server с демо
npm test             # юнит- и компонентные тесты
npm run coverage     # отчёт: packages/json-highlighters/coverage/
npm run build        # сборка библиотеки и демо
npx playwright install chromium # однократная установка браузера для E2E
npm run test:e2e     # сборка библиотеки, затем Playwright против dev server демо
```

Для изменений библиотеки запустите во втором терминале
`npm run dev --workspace=packages/json-highlighters`. Watch-режим пересобирает
JavaScript и декларации типов; после изменения CSS нужна команда
`npm run copy:css --workspace=packages/json-highlighters` или полная сборка библиотеки.
